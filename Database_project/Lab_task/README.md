Спроектирована база данных для учёта киберспортивных турниров.  
**Стек:** PostgreSQL, реляционная алгебра.  

**Файлы:**  
- `База Данных. Лабораторная.docx` – отчёт с ER-моделью, схемой, запросами для создания таблиц и их заполнения данным для примера, запросы на поиск определённой информации.
