# Тестовое задание «СКУД»

Система контроля доступа в офис: учёт времени сотрудников.  
**Стек:** PostgreSQL, Python (psycopg2).  

**Файлы:**
- `задание.docx` – постановка задачи.  
- `отчет.docx` – описание решения.  
- `тест2.rar` – набор .txt файлов с запросами от создания БД до скрипта на питоне

В таблице намерено добавлены две лишние таблицы "Рабочие_сессии" и "Отчеты_по_времени", созданные для сверки данных, полученных в скрипте.
